### What's new

#### Review a batch before it is committed

Tap any page in the strip under the shutter and it opens in the review, which steps backwards
and forwards through the whole run rather than only the handful of pages the strip has room for.
From there you can rotate a page a quarter turn or turn it over, without leaving the flow you
were in. A page the automatic orientation pass could not decide is labelled as such in the
review rather than presented as a confident guess.

#### Pages that arrived upside down

Fixed. The upside-down cue measures a row profile inside each text band, and it was reading that
profile only down to 30% of its peak. That cut off the ascender and descender rows, which are
where the asymmetry the cue depends on actually lives, so pages carrying a perfectly good signal
were being left turned over. The band measurement now keeps those rows, and far more photographed
pages come back upright on the first pass.

### A limitation we are not hiding

On a page of dense, uniform prose — little in the way of ascenders, descenders, capitals or
headings — the cue still cannot decide reliably, at any resolution the app can afford to compute.
Rather than pick an orientation and hope, the app records that it could not tell. In the review
you see **"Upside down? The automatic pass could not tell"** with a one-tap flip beside it. That
is a choice we make deliberately, rather than silently shipping a page the wrong way up: a page
you have to turn over is obvious, a page filed upside down is not.

### Also in this release

- One-tap page flip.
- Delete confirmations that name what is going and how many — "Delete this document?" versus
  "Delete 4 documents?" — followed by a report of how many were deleted.
- Import results are reported in the library, so an import says how many images came in and how
  many failed instead of appearing to do nothing.
- The app version is shown in Settings, read from the installed package rather than typed into a
  label.
- The permission screen now routes to the system settings page for KScanner and re-checks when
  you come back, so granting a permission no longer needs a restart.
- Back arrows are direction-aware, so they point the right way in right-to-left layouts.
- Backup is switched off: the manifest sets `android:allowBackup="false"`, so scans, thumbnails
  and the OCR database are excluded from Android's cloud backup and from device-to-device
  transfer — which is what makes the Settings line "stored entirely on this device" literally
  true.

### Known issues

- Folder support is unreachable end to end. No code assigns a document to a folder — every
  document is created with a null folder — so the folder filter never appears at all; and if one
  ever did, the row would only ever show three folders.
- Rename works on one document at a time: with more than one selected the Rename action is not
  offered at all. Bulk delete is correct.
- In the editor, **Detect** discards a manual rotation: re-running detection resets the corners
  to the detected quad.
- Rotating a page does not invalidate the stored OCR line boxes, so text selection on a rotated
  page can still point at the pre-rotation positions.
- `sweepCaptures`, the cleanup of stale capture files, is written but not called from anywhere.
