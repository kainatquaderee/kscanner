### What's new

#### The page is framed on the viewfinder, not after the shot

The camera now draws the border it has found around the page, while you are still pointing the
phone at it, and dims everything outside that border. What will be kept is what you see before you
press the shutter, instead of something you find out about on the crop screen afterwards.

We keep it always on. There is no setting for it, because there is no moment at which it should be
off: it never covers a control, never changes what is captured, and clears itself as soon as there
is no page in view.

#### The border follows the page, it does not chase every frame

A border redrawn from scratch sixty times a second would shimmer with the camera's noise, and one
that vanished the moment a line was lost would flicker. So we made the outline on screen a memory
of what has been detected, and it behaves like one:

- It moves when the page moves. Movement is eased into place rather than snapped, so it slides.
- It ignores your hand. Corners that shift by less than five density-independent pixels are the
  same outline seen through noise, and it does not twitch for them.
- It waits before giving up. A frame or two in which the page cannot be found — a shadow passing, a
  blurred moment — does not take the border away; about a third of a second without a good
  detection does.
- It would rather show nothing than guess. An outline the detector is not reasonably confident
  about is not drawn at all, and the live path uses only the line detector: the fallbacks that help
  on a still photograph would draw a box around the text, which reads as the page edge.

We ask for detection about seven times a second, not on every frame, on the same small grayscale
image the automatic shutter already measures. It costs a few milliseconds of a frame budget that is
otherwise idle.

### Also in this release

- **The automatic shutter is untouched.** It still fires on the same measurements, with the same
  unhurried wait. The framing overlay neither triggers it nor feeds it.
- **Turning the automatic shutter on or off no longer restarts the preview.** The frame analysis
  used to be bound only while it was on, and rebinding it restarted the camera. We now keep it
  bound, which the overlay needs in any case.
- The overlay sits over the preview and under every control, so it cannot swallow a tap on the
  shutter, the torch, the zoom chips, the shape chips or the page strip.

### Known issues

- **The live outline is found on a subsampled frame.** The preview's grayscale image is made small
  for detection by skipping pixels rather than averaging them, so the detector sees a slightly more
  aliased picture here than it does on a photograph you import. On a busy background that can cost
  the live border confidence that a still shot keeps.
- Folder support is unreachable end to end. No code assigns a document to a folder — every
  document is created with a null folder — so the folder filter never appears at all.
- Rename works on one document at a time: with more than one selected the Rename action is not
  offered at all. Bulk delete is correct.
- In the editor, **Detect** discards a manual rotation: re-running detection resets the corners
  to the detected quad.
- Rotating a page does not invalidate the stored OCR line boxes, so text selection on a rotated
  page can still point at the pre-rotation positions.
- `sweepCaptures`, the cleanup of stale capture files, is written but not called from anywhere.
